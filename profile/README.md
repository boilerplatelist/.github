# BoilerplateList

**A directory of the best boilerplates and starter kits for developers and founders who ship fast.**

Picking a starter kit shouldn't take longer than building the product. [boilerplatelist.com](https://boilerplatelist.com) collects SaaS, web and mobile boilerplates in one place, so you can compare them by stack, pricing and features, and get back to shipping.

## By platform

- [SaaS Boilerplates](https://boilerplatelist.com/saas-boilerplates/)

- [Browser Extension Boilerplates](https://boilerplatelist.com/browser-extension-boilerplates/)
